# 🌊 Biblioteca pública — Veeduría Guardianes del Río

Sitio de consulta pública de la **Veeduría Ambiental Guardianes y Guardianas de los
Ríos Cauca, Las Piedras, Molino y Pisojé** (Popayán, Cauca · Ley 850/2003).

**URL:** https://veeduria-guardianes.github.io/biblioteca/

Construido con [Quartz](https://quartz.jzhao.xyz) a partir de una **copia curada**
de la bóveda interna: solo contenido público (fichas, expedientes según registros
ANM, marco legal, actas oficiales, documentos descargados). La estrategia interna
de la veeduría **no** vive en este repositorio.

## Actualizar el sitio

1. Edita las notas en `content/` (Markdown normal, enlaces `[[...]]`).
2. `git commit` + `git push` — GitHub Actions reconstruye y publica solito (~2 min).

Regla de la casa: toda cifra con fuente y fecha; jamás datos de miembros del equipo.
